# ADR-013 두 번째 팩: 전문 소프트웨어(ngspice) 위의 에이전트

날짜: 2026-10-28 · 상태: 채택

## 문제
README 는 "도메인은 팩으로 교체한다" 고 주장했지만 팩이 하나(회사 데이터 비서)뿐이면 주장일 뿐이다. 두 번째 팩은 성격이 달라야 증명이 된다: DB 조회가 아니라 **외부 전문 프로그램을 실행하고 그 결과를 해석하는** 도메인. 회로 시뮬레이터 ngspice 를 골랐다. 입력이 글(넷리스트)이라 LLM 이 쓰기 좋고, 정답을 물리 공식으로 미리 알 수 있어 평가가 자동화되며, 반복 실행(스윕)이 "오래 걸리는 작업" 의 실제 사례가 된다.

## 결정
1. **팩 인터페이스를 명시한다** (`harness/packs/__init__.py` 의 `Pack`). 도구 묶음, 프롬프트 버전, 범위 파서, 공유 자원(문서 색인), 평가 태스크 경로, 화면용 라벨·예시, 서빙할 파일 폴더. 플랫폼(루프·권한·서비스·평가·트레이스·MCP)은 이것만 보고 돈다. 선택은 `HARNESS_PACK` 또는 `--pack`. 검색 모듈은 도메인 중립이라 `harness/retrieval/` 로 올렸다.
2. **넷리스트는 SQL 처럼 가드한다.** 허용 목록 방식: 소자 줄과 회로 기술 지시문(.model/.subckt/.param/.option …)과 해석 지시문만 통과. 파일을 읽는 `.include/.lib`, 명령을 실행할 수 있는 `.control`, 출력 지시문은 거부. 제어 블록(측정·저장·종료)은 시뮬레이터 모듈이 직접 만든다. 측정식은 "이름 형식 …" 문자열로 받고 글자 허용 목록과 형식 목록으로 걸러 제어 블록 주입을 막는다. 모델이 습관적으로 넷리스트에 쓰는 `.measure` 는 거부하지 않고 측정식으로 흡수한다(경고만).
3. **소형 모델 실수는 도구가 고치거나 설명한다.** 첫 줄을 제목으로 삼키는 ngspice 규칙(제목 줄 자동 삽입), `1M` = 밀리(경고), 참조한 노드·전원이 없을 때(실행 전에 목록과 함께 거절), 측정이 범위를 벗어났을 때(값 None + 파형 도구 안내), 해석 크기 상한(점수 추정 200만 초과 거절), 시간 제한 20초.
4. **그래프는 SVG 를 직접 만든다.** 그래프 라이브러리 의존 없이 축·격자·로그 스케일·측정 표시·범례를 그린다. 결과 딕셔너리의 `url` 을 루프가 `tool_result` 이벤트에 실어 보내고, 화면은 그 자리에 그림을 넣는다. 팩이 선언한 폴더를 서비스가 `/files/<팩>` 으로 서빙한다.
5. **스윕은 Python 반복 + 잡 큐.** ngspice 제어 언어의 foreach 보다 Python 반복이 오류 처리·부분 실패 기록이 쉽다. 점당 10~30 ms 라 60점 상한에서도 몇 초지만, 화면에서는 `/jobs` 로 보내 "오래 걸리는 작업은 큐에서" 를 그대로 쓴다.
6. **평가 정답은 공식이다.** `truth_expr`(안전한 산술 평가기: 사칙연산·거듭제곱·math 함수·pi 만) 과 `tolerance_pct` 를 러너에 추가. 답변 속 숫자는 SI 접두사(kHz, µs, mA)와 한글 단위를 풀어 기본 단위로 비교하고, 부호는 무시한다(전원 전류 관례). 시뮬레이터 격자 오차(0.2~0.5%)를 감안해 2~3%.

## 대안과 기각 이유
- PySpice/ngspice 공유 라이브러리 바인딩: 설치가 플랫폼마다 달라 재현성이 떨어진다. 서브프로세스 + 텍스트 출력 파싱은 어디서나 같다.
- 모델에게 `.control` 블록까지 쓰게 하기: 표현력은 크지만 `shell` 등 명령 실행 경로가 열린다. 측정식만 받는 쪽이 SQL 가드와 같은 원칙이다.
- matplotlib: 의존성과 폰트 문제. SVG 직접 생성이 가볍고 화면·README 에 그대로 들어간다.

## 결과
- 플랫폼 코드 변경은 팩 선택 지점뿐(CLI 4곳, 서비스 1곳, 평가 러너, MCP). 팩 폴더 하나(`harness/packs/spice/`, 도구 11개·문서 6개·샘플 회로 6개)로 화면 머리말·예시·타임라인 라벨까지 바뀐다.
- 새로 발견한 소형 모델 실패 모드 2개를 플랫폼에 보정으로 넣었다(ADR-004 보강): 추론 토큰이 출력 예산을 다 써 **본문이 빈 채 length 로 끝나는 경우** 는 한 번 되묻고(기본 max_tokens 도 1024 → 2048), 넷리스트 안의 `.measure` 습관은 흡수.
- 평가 16문제(해석 8·스윕 2·문서 2·저장 1·함정 3) 결과는 README 평가 절.
