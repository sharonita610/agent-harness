# ADR-021 MCP 를 HTTP 로 열되, 같은 키·범위·결재함을 쓴다

날짜: 2026-10-29 · 상태: 채택

## 문제
MCP 서버는 표준 입출력(stdio)뿐이라 같은 컴퓨터의 클라이언트(Claude Desktop, Cursor, Hermes)만 붙을 수 있었다. 회사 안에서 한 서버를 여러 사람이 쓰려면 네트워크로 열어야 하는데, 그러면 세 가지가 비어 있었다: 누가 부르는지(인증), 그 사람이 무엇까지 볼 수 있는지(데이터 범위), 변경 도구를 누가 승인하는지(결재). stdio 에서는 "클라이언트 쪽 사람이 확인한다" 에 맡겨 두었는데, 여러 사람이 쓰는 순간 그 가정이 깨진다.

## 결정
1. **같은 서비스 포트의 `/mcp/`.** 별도 프로세스가 아니라 FastAPI 앱에 MCP streamable HTTP 앱을 마운트한다(`harness/mcp_server/http.py`). 그래서 웹 화면·API·A2A·MCP 가 **같은 저장소, 같은 결재 브로커, 같은 사용자 파일**을 쓴다. 새 엔진이 없다는 ADR-017 의 원칙 그대로.
2. **인증은 웹 API 와 같은 키.** `Authorization: Bearer <키>`. 사용자 파일이 있으면 필수(없으면 401), 없으면 개발 모드. ASGI 미들웨어가 키를 확인해 사용자를 contextvar 에 두고, 도구 핸들러가 그 사용자로 실행한다.
3. **범위는 사용자별 레지스트리.** 웹 채팅이 쓰는 `registry_for(user)` 를 그대로 써서, 부산 담당자는 MCP 로도 부산 주문만 본다. 범위 밖 주문은 "없음" 으로 보인다(임시 뷰가 잘라서). 역할은 operator 이상만 도구를 부를 수 있다.
4. **변경 도구는 결재함을 거친다.** write 등급 도구 호출은 실행 기록(kind=mcp)과 결재 전표를 만들고 승인될 때까지 기다린다. 화면 결재함에 "[MCP · ops] create_note …" 전표가 뜨고, 승인하면 실행되어 결과가 MCP 클라이언트로 돌아가며, 반려·기한 만료면 실행하지 않고 그 사실을 돌려준다. 실행 기록에는 tool_call → approval_pending → approval_result → tool_result → final 이벤트가 남아 기록 탭에서 작업지로 다시 열린다. destructive 는 여전히 노출하지 않는다.
5. **감사 기록.** 읽기 호출은 `mcp_call`, 결재 요청은 `mcp_approval_requested` 로 누가 어떤 도구를 어떤 인자로 불렀는지 남는다.
6. **stdio 는 그대로.** 로컬 1인용은 지금처럼 `harness mcp`. 같은 래퍼(`wrap_tool`)에 실행 함수만 바꿔 끼운다.

## 결과
- 테스트 6개: 키 없으면 401, destructive 미노출과 힌트, 범위 적용(부산 < 전체)과 감사, 결재 승인 후 실행과 기록 이벤트 순서, 반려 시 미실행, viewer 거부, 범위 밖 주문 거절.
- 도구 오류 문장(범위 밖, 형식 오류)은 MCP 의 ToolError 로 감싸 클라이언트에 그대로 보인다. 처음엔 SDK 가 "Error executing tool" 로 가려 버렸다.

## 대안과 기각 이유
- **MCP 표준 OAuth(토큰 검증기).** SDK 가 지원하지만 인가 서버가 따로 필요하다. 이 프로젝트의 사용자 모델(해시 키 + 역할 + 범위)을 그대로 쓰는 쪽이 작고, 웹과 MCP 가 한 키로 통한다.
- **별도 MCP 프로세스.** 결재 브로커와 저장소를 공유하려면 어차피 같은 프로세스가 낫다. 포트도 하나 줄어든다.
- **변경 도구를 MCP 에서 즉시 실행하고 사후 감사.** HITL 결정(ADR-002)과 어긋난다.

## 한계
- 승인을 기다리는 동안 MCP 호출이 열려 있다(기본 결재 기한 600초). 클라이언트의 도구 시간 제한이 더 짧으면 호출은 끊기지만 전표는 남아 있어 승인 시 실행된다. 그 결과는 기록 탭에서 본다.
- Host 헤더 검사(DNS 리바인딩 방어)는 `HARNESS_MCP_ALLOWED_HOSTS` 를 줄 때만 켠다. 키 인증이 있어 기본은 끈다.
- 리소스(문서)는 범위와 무관하게 전부 보인다. 규정 문서라 괜찮다.
