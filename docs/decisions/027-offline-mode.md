# ADR-027 오프라인(에어갭) 모드: 밖으로 나가는 호출이 없음을 설정이 아니라 코드와 테스트로

날짜: 2026-10-30 · 상태: 채택

## 배경

은행·병원·군·원전·공장처럼 데이터를 건물 밖으로 내보낼 수 없는 곳에서는 "AI 도 안에서 돌아야" 한다. 이 플랫폼은 처음부터 로컬 모델·SQLite·BM25·로컬 ngspice 위에 있어서 기본값으로는 밖에 나가지 않지만, 세 군데가 설정에 따라 나갈 수 있었다: 모델 공급자(`openai:`·`anthropic:`·`compat:바깥주소`), 임베딩 서버 주소, 트레이스 내보내기 주소. 그리고 화면이 글꼴(Pretendard)을 CDN 에서 받고 있었다. "설정을 잘못 해도 안 나간다" 가 되려면 설정이 아니라 코드가 막아야 하고, 그 사실을 테스트가 증명해야 한다.

## 결정

1. **`HARNESS_OFFLINE=1` 모드** (`harness/offline.py`). 켜면 외부 공급자 종류는 만들지 않고, 모델·임베딩·트레이스 주소는 `check_url` 을 거쳐 루프백·사설망(10/8, 172.16/12, 192.168/16, 169.254/16, fc00::/7)·점 없는 사내 호스트명만 허용한다. 바깥 주소면 시작 시 `OfflineViolation` 으로 멈춘다(조용히 무시하지 않는다). 예외는 `HARNESS_OFFLINE_ALLOW`(호스트 또는 `.corp.local` 같은 접미사)로만. 임베딩 서버가 바깥이면 탐색조차 하지 않고 BM25 만 쓴다. `/health` 가 `offline: true` 를 보여 준다.
2. **글꼴 동봉.** Pretendard Variable(SIL OFL)을 `ui/public/fonts/` 에 넣고 `@font-face` 로 쓴다. 화면의 유일한 외부 요청이 없어진다.
3. **모델·임베딩 서버 스크립트**는 오프라인 모드에서 Hugging Face 다운로드를 거부하고 파일 경로(`LLM_MODEL_PATH`, `EMBED_MODEL_PATH`)를 요구한다.
4. **설치 묶음** `scripts/offline_bundle.sh`: 인터넷이 되는 곳에서 도커 이미지(tar) 또는 소스+uv 휠 캐시+빌드된 화면을 모델 파일과 함께 묶고 `INSTALL.md` 를 넣는다. 대상 서버에서는 `docker load` 또는 `uv sync --offline` 으로 설치한다.
5. **증명 테스트** `tests/test_offline.py`: 루프백이 아닌 소켓 연결을 전부 실패시키는 가드를 걸고 평가 한 바퀴(회사 팩, 도구·DB·검색·채점)를 돌려 통과하는지 본다. 외부 공급자·바깥 주소가 거부되는지, 사설망·사내 호스트명이 허용되는지도 본다.
6. **모델 라우팅**은 바깥 모델로 올리는 기능이므로 오프라인에서는 "작은 로컬 → 큰 로컬"(`route:local->compat:http://llm-big:8080/v1|m`)로만 쓴다. 프로바이더가 둘 다 로컬이면 코드는 같다.

## 결과

- 런타임에 밖으로 나가는 경로 0. 빌드·설치 시 필요한 것(파이썬 휠, node 패키지, 도커 베이스 이미지, 모델 파일)은 묶음 스크립트가 바깥에서 한 번에 모은다.
- 테스트 소켓 가드 아래에서 평가가 통과한다(결과는 README).

## 대안과 기각 이유

- **네트워크 정책(방화벽)에만 맡김.** 운영 환경에서는 당연히 있어야 하지만, 애플리케이션이 스스로 거부하지 않으면 "왜 안 되지" 로 시간을 쓰고, 방화벽이 없는 개발 환경에서는 새어 나간다. 둘 다 있어야 한다.
- **바깥 주소를 조용히 무시하고 로컬로 대체.** 설정 실수를 숨긴다. 시작 시 멈추는 쪽이 맞다.
- **글꼴을 시스템 글꼴로 대체.** 윈도우·리눅스 서버에서 화면이 달라진다. 2 MB 파일 하나로 끝나는 일이라 동봉했다.

## 한계

- 점 없는 호스트명을 허용하므로 사내 DNS 가 바깥으로 풀어 주면 막지 못한다. 그 층은 방화벽의 몫이다.
- 인증(CC·ISMS-P·FIPS), 서명된 이미지와 SBOM, 사내 계정 연동, 스니커넷 업데이트 절차는 이 ADR 밖이다. 포트폴리오가 아니라 제품의 일이다.
