# 주문 상태 정의

문서번호: OPS-001 | 개정일: 2026-03-02 | 담당: 운영팀

## 상태 목록

| 상태 | 의미 | 다음 가능 상태 |
|---|---|---|
| 접수 | 주문이 등록되었고 결제 확인 전 또는 출고 준비 중 | 출고, 지연, 취소 |
| 출고 | 창고에서 상품이 나갔음 (shipped_date 기록) | 배송중, 완료 |
| 배송중 | 운송사가 배송 중 | 완료 |
| 완료 | 고객이 수령 (delivered_date 기록) | 없음 |
| 지연 | 출고 예정일을 넘겼으나 출고되지 않았거나 늦게 출고됨 | 출고, 취소 |
| 취소 | 주문 무효 처리 | 없음 |

## 지연 사유 코드

- 재고 부족: 주문 시점에 안전재고 미달로 출고 불가. 회사 책임 사유.
- 배송사 지연: 운송사 사정. 회사 책임 아님.
- 주소 오류: 고객 제공 주소 불일치. 고객 책임.
- 결제 확인 지연: 입금 확인이 늦어진 경우. 공동 책임.

## 상태 변경 권한

상태 변경은 운영팀 또는 CS팀 담당자가 사유를 기록하고 수행한다. 시스템이나 자동화 도구가 상태를 바꿀 때는 반드시 담당자의 승인을 먼저 받아야 하며, 승인 없는 자동 변경은 금지한다.
