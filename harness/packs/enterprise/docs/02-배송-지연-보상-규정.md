# 배송 지연 보상 규정

문서번호: CS-002 | 개정일: 2026-05-10 | 담당: CS팀

## 적용 범위

출고 예정일(planned_date)보다 실제 출고(shipped_date)가 늦었거나, 상태가 "지연"인 모든 주문에 적용한다. 지연 일수는 출고 예정일 다음 날부터 실제 출고일까지로 계산한다. 아직 출고되지 않은 주문은 오늘 날짜 기준으로 계산한다.

## 보상 비율

| 지연 일수 | 보상 | 비고 |
|---|---|---|
| 1~2일 | 보상 없음 | 사과 안내 문자 발송 |
| 3~5일 | 주문 금액의 3% | 다음 주문 할인 쿠폰 또는 환불 |
| 6~10일 | 주문 금액의 5% | |
| 11일 이상 | 주문 금액의 10% | 고객이 원하면 전액 취소 가능 |

지연 사유가 "재고 부족"이면 회사 책임 사유이므로 위 비율에 2%p를 추가한다. 지연 사유가 "주소 오류"이면 고객 책임이므로 보상하지 않는다. "배송사 지연"은 위 표를 그대로 적용하되 운송사에 구상 청구한다.

## 승인자

| 보상 금액 | 승인자 |
|---|---|
| 50만 원 이하 | CS팀장 |
| 50만 원 초과 300만 원 이하 | 영업부서장 |
| 300만 원 초과 | 대표 |

## 절차

1. CS 담당자가 주문 번호, 지연 일수, 사유, 보상 금액을 기록한다.
2. 위 표의 승인자가 승인한다.
3. 승인 후 주문에 메모를 남기고 고객에게 안내한다.
