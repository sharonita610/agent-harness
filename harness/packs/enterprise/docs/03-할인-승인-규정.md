# 할인 승인 규정

문서번호: SALES-003 | 개정일: 2026-01-15 | 담당: 영업팀

## 기본 할인

- 등급 A 거래처는 모든 주문에 기본 3% 할인을 적용한다.
- 등급 B, C 거래처는 기본 할인이 없다.

## 추가 할인 승인자

할인율과 할인 금액 중 더 높은 단계의 승인자가 승인한다.

| 조건 | 승인자 |
|---|---|
| 할인율 5% 이하 그리고 할인 금액 30만 원 이하 | 영업 담당자 본인 |
| 할인율 10% 이하 또는 할인 금액 100만 원 이하 | 영업팀장 |
| 할인율 20% 이하 또는 할인 금액 500만 원 이하 | 영업부서장 |
| 할인율 20% 초과 또는 할인 금액 500만 원 초과 | 대표 |

## 금지 사항

- 승인 없이 시스템에 할인율을 직접 수정하는 행위.
- 한 주문을 쪼개어 승인 단계를 낮추는 행위.
- 등급 C 거래처에 10%를 초과하는 할인을 제안하는 행위(부서장 사전 협의 필요).
