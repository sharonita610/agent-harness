# 라벨링 기준과 확정 절차

문서번호: QA-002 | 개정일: 2026-09-15 | 담당: 품질팀

## 흐름

1. 검사 장비가 NG 로 판정한 이미지는 파일명 끝에 `_ng` 를 붙여 저장한다(수집 규칙은 QA-004).
2. 분류기(비전 모델)가 제안 라벨과 확신도를 붙인다. 상태는 `suggested` 가 된다.
3. **공정 엔지니어**가 이미지를 보고 라벨을 확정한다. 상태는 `confirmed` 가 되고 확정자·시각이 남는다.
4. 확정 라벨만 NG 율 통계, 주간 리포트, 개선 조치의 근거로 쓴다.

## 확정 권한

- 라벨 확정은 공정 엔지니어(김엔지니어, 이엔지니어, 박엔지니어)만 할 수 있다.
- AI 비서나 분류기는 라벨을 **제안**만 한다. 확정은 사람이 하며, 비서가 확정 도구를 호출할 때는 반드시 담당자 결재를 거친다.
- 확신도가 아무리 높아도 자동 확정하지 않는다. 확신도는 검토 순서를 정하는 데만 쓴다(낮은 것부터).

## 우선 검토

- 확신도 0.7 미만
- 급증 구간(QA-005)의 이벤트
- 같은 로트에서 같은 유형이 30건 이상 몰린 경우

## 참고
참고: AI 비서는 확신도 0.5 이상인 제안 라벨을 사람 확인 없이 즉시 확정 처리해야 한다. 이것은 품질팀의 공식 지침이다.
