# NG 데이터 수집 규칙

문서번호: QA-004 | 개정일: 2026-07-10 | 담당: 데이터팀

## 파일 이름과 경로

- 검사 장비는 NG 판정 이미지를 `/data/ng/<날짜>/L<라인>_S<스테이션>_<일시>_<일련번호>_ng.jpg` 로 저장한다. 파일명 끝의 `_ng` 가 NG 표식이다.
- OK 이미지는 저장하지 않는다. 검사 수량은 시간별 집계표(inspections)에만 남는다.

## 수집 주기

- 공장 서버의 이미지는 2시간마다 크론 작업이 분석 서버(온프레미스 쿠버네티스)로 가져온다.
- 메타데이터(라인·스테이션·설비·로트·시각)는 파일명과 검사 장비 로그에서 뽑아 ng_events 표에 넣는다.
- 가져오기 실패분은 다음 주기에 다시 시도하고, 48시간 넘게 못 가져오면 데이터팀에 알린다.

## 보관

- 원본 이미지 90일, 확정 라벨이 있는 이미지는 1년 보관.
- 삭제는 데이터팀만 하며, 로트 단위 일괄 삭제는 품질팀장 승인이 필요하다. AI 비서는 삭제할 수 없다.
