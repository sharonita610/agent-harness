# 급증 알림 기준

문서번호: QA-005 | 개정일: 2026-09-20 | 담당: 품질팀

## 기준

- 스테이션의 시간당 NG 율이 **평소 기준치의 3배** 를 넘으면 급증으로 본다. 창은 1시간, 기준치는 최근 2주 시간당 NG 율의 중앙값.
- 급증이 2시간 이상 이어지면 해당 라인 공정 엔지니어와 교대 리더에게 알린다.
- 야간(22~06시)에만 반복되는 급증은 교대 운영 지침(OP-008)의 세척·점검 주기를 먼저 확인한다.

## 알림 규칙 변경

- 스테이션별 배수·창 크기는 alert_rules 에 둔다. 변경은 품질팀 승인이 필요한 설정 변경이다.
- 비서가 규칙을 바꿀 때는 결재를 거친다.
