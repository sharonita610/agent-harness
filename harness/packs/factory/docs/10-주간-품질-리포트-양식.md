# 주간 품질 리포트 양식

문서번호: QA-010 | 개정일: 2026-09-25 | 담당: 품질팀

## 항목

1. 라인별 NG 율(검사 수량 대비 확정 NG), 전주 대비 변화
2. 스테이션별 상위 3개 불량 유형
3. 급증 이벤트 목록(라인·스테이션·시작·종료·배수·원인 후보)
4. 조치 티켓 현황(신규·진행·완료)과 효과 검증 결과
5. 미확정 라벨 수와 확신도 0.7 미만 건수

## 작성 규칙

- 숫자는 데이터에서 직접 집계한다. 추정치는 쓰지 않는다.
- 이미지는 넣지 않는다(SEC-009). 경로나 일련번호로 가리킨다.
