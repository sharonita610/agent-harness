# 넷리스트 기본 문법

문서번호: SPICE-001 | 대상: ngspice 47 | 작성: 시뮬레이션 비서 팩 참고 자료(매뉴얼 요약)

## 파일 구조

- 첫 줄은 무조건 제목이다. 첫 줄에 소자를 쓰면 그 소자는 회로에서 사라진다. 제목은 `* ` 로 시작하는 주석 형태로 쓰는 것이 안전하다.
- 각 줄은 소자 하나 또는 `.` 으로 시작하는 지시문 하나다. `+` 로 시작하는 줄은 앞 줄의 연속이다.
- 주석은 `*` 로 시작하는 줄, 또는 줄 끝의 ` ; ` 뒤다.
- 마지막 줄은 `.end` 다(비서 도구는 없으면 자동으로 붙인다).
- 대소문자를 구분하지 않는다. `R1` 과 `r1` 은 같은 소자다.

## 노드와 접지

- 노드 이름은 숫자나 문자열 모두 가능하다(`in`, `out`, `n1`, `3`).
- 기준 노드(접지)는 반드시 `0` 이다. `gnd` 는 ngspice 에서 0 으로 취급되지만 `0` 을 쓰는 것이 확실하다.
- 모든 노드는 접지까지 직류 경로가 있어야 한다. 커패시터만으로 접지에 연결된 노드는 "singular matrix" 오류를 낸다.
- 어떤 노드에 소자가 하나만 붙어 있으면 떠 있는 노드다. 해석이 실패하거나 의미 없는 값이 나온다.

## 소자 줄 형식

| 첫 글자 | 소자 | 형식 | 예 |
|---|---|---|---|
| R | 저항 | `Rname n+ n- 값` | `R1 in out 1k` |
| C | 커패시터 | `Cname n+ n- 값` | `C1 out 0 100n` |
| L | 인덕터 | `Lname n+ n- 값` | `L1 in n1 1m` |
| V | 전압원 | `Vname n+ n- [dc 값] [ac 크기] [파형]` | `V1 in 0 dc 0 ac 1` |
| I | 전류원 | `Iname n+ n- [dc 값] [ac 크기]` | `I1 0 out dc 1m` |
| D | 다이오드 | `Dname 애노드 캐소드 모델` | `D1 in out D1N4148` |
| Q | BJT | `Qname C B E 모델` | `Q1 c b e NPN1` |
| M | MOSFET | `Mname D G S B 모델 [W= L=]` | `MN out in 0 0 NMOS W=10u L=1u` |
| X | 서브서킷 호출 | `Xname 노드… 서브서킷이름` | `X1 in out opamp1` |

전압원의 전류는 `i(Vname)` 으로 잰다. 전류 방향은 양극(n+)에서 들어가 음극으로 나가는 쪽이 양수라서, 회로에 전류를 공급하는 전원의 `i(V1)` 은 음수로 나온다.

## 값과 접미사

SPICE 접미사는 대소문자를 구분하지 않는다. 그래서 `M` 은 메가가 아니라 밀리다.

| 접미사 | 배수 | 예 |
|---|---|---|
| T | 1e12 | |
| G | 1e9 | |
| meg | 1e6 | `1meg` = 1,000,000 (메가) |
| k | 1e3 | `4.7k` |
| m | 1e-3 | `1m` = 0.001 (밀리). `1M` 도 밀리다 |
| u | 1e-6 | `4.7u` |
| n | 1e-9 | `100n` |
| p | 1e-12 | `22p` |
| f | 1e-15 | |

접미사 뒤에 단위 글자가 붙어도 무시된다. `10mH`, `100nF`, `1kOhm` 은 각각 `10m`, `100n`, `1k` 와 같다. 1메가옴 저항은 `1meg` 이지 `1M` 이 아니다.
