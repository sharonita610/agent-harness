# 해석 종류와 결과 벡터

문서번호: SPICE-002 | 대상: ngspice 47

## .op 동작점 해석

`.op`
모든 노드의 직류 전압과 전압원 전류를 한 점에서 구한다. 분압기, 바이어스 점, 소비 전력 계산에 쓴다. 측정식 없이 결과 벡터(`out`, `in`, `v1#branch`)가 그대로 나온다.

## .dc 직류 스윕

`.dc 소스이름 시작 끝 간격`
예: `.dc VIN 0 3.3 0.01` 은 VIN 을 0 V 부터 3.3 V 까지 0.01 V 간격으로 바꾸며 각 점의 직류 해를 구한다. 전달 특성 곡선(인버터, 다이오드 I-V)에 쓴다. 스케일 벡터는 `v-sweep` 이다. 두 소스를 중첩 스윕하려면 뒤에 두 번째 소스를 같은 형식으로 덧붙인다.

## .ac 교류 소신호 해석

`.ac dec 점수/decade 시작주파수 끝주파수`
예: `.ac dec 20 10 1meg` 은 10 Hz 부터 1 MHz 까지 10배마다 20점. `lin`(선형), `oct`(옥타브)도 있다. 입력 전압원에 `ac 1` 을 주면 출력 전압이 곧 전달함수가 된다. 결과는 복소수이고 `vdb(out)` 로 데시벨 크기, `vp(out)` 로 위상(도), `vm(out)` 으로 크기를 본다. 스케일 벡터는 `frequency` 다.

점수가 적으면 -3 dB 같은 교차점 측정이 격자 사이에서 보간되어 0.2~0.5% 정도 오차가 난다. 정밀하게 재려면 `dec 100` 이상으로 올린다.

## .tran 과도 해석

`.tran 시간간격 끝시간 [시작시간] [최대간격]`
예: `.tran 1u 1m` 은 0 부터 1 ms 까지 1 µs 간격으로 시간 응답을 구한다. 계단 응답, 시정수, 상승 시간, 정착 시간에 쓴다. 스케일 벡터는 `time` 이다. 끝시간/시간간격이 수백만 점을 넘으면 메모리와 시간이 급격히 늘어난다.

## 결과 벡터 이름

| 벡터 | 뜻 |
|---|---|
| `v(out)` | 노드 out 의 전압 |
| `v(a,b)` | 두 노드 사이 전압 |
| `vdb(out)` | 20·log10|v(out)| (교류 해석) |
| `vp(out)` | 위상(도) |
| `i(V1)` | 전압원 V1 에 흐르는 전류(내부 이름 `v1#branch`) |

저항 전류는 직접 벡터가 없으므로 전압 차를 저항값으로 나누거나, 0 V 전압원을 직렬로 넣어 `i()` 로 잰다.
