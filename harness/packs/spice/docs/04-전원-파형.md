# 전원과 파형

문서번호: SPICE-004 | 대상: ngspice 47

## 직류·교류 지정

`V1 in 0 dc 12` 직류 12 V.
`V1 in 0 dc 0 ac 1` 직류 0 V 에 교류 소신호 크기 1(위상 0). 교류 해석은 선형화 해석이라 크기 1 을 주면 출력이 곧 전달함수다.
`V1 in 0 12` 처럼 `dc` 를 생략해도 직류 값으로 읽는다.

## PULSE 계단·펄스

`PULSE(V1 V2 TD TR TF PW PER)`
V1 에서 V2 로 TD 뒤에 TR 동안 올라가고, PW 동안 유지한 뒤 TF 동안 내려오며, PER 마다 반복한다. 계단 입력은 `PULSE(0 1 0 1n 1n 10m 20m)` 처럼 펄스 폭을 해석 시간보다 길게 잡는다. TR·TF 를 0 으로 두면 ngspice 가 시간간격으로 대체한다.

## SIN 정현파

`SIN(VO VA FREQ TD THETA)`
오프셋 VO, 진폭 VA, 주파수 FREQ. 예: `SIN(0 1 1k)` 는 1 kHz, 진폭 1 V. 정상 상태 진폭·왜곡은 과도 해석 뒤 RMS/PP 측정으로 본다.

## PWL 구간 선형

`PWL(t1 v1 t2 v2 …)` 시간·전압 쌍을 직선으로 잇는다. 램프나 임의 파형에 쓴다.

## 전류원

`I1 0 out dc 1m` 은 접지에서 out 쪽으로 1 mA 를 밀어 넣는다(노드 순서가 전류 방향이다).
