# 자주 쓰는 해석 공식

문서번호: SPICE-005 | 용도: 시뮬레이션 값과 이론값 비교

시뮬레이션은 사실을 확인하는 수단이고, 공식은 결과가 말이 되는지 확인하는 기준이다. 답할 때는 시뮬레이션 값을 먼저 말하고 공식값과의 차이를 덧붙인다.

## 1차 RC 필터

- 차단 주파수(-3 dB): fc = 1 / (2π R C)
- R = 1 kΩ, C = 100 nF 이면 fc = 1 / (2π · 1000 · 1e-7) = 1591.5 Hz
- 저역통과는 fc 위에서 -20 dB/decade, 고역통과는 fc 아래에서 -20 dB/decade
- fc 에서 위상은 ∓45°

## RC 계단 응답

- 시정수 τ = R C. 출력이 최종값의 63.2% 에 이르는 시간
- 10%→90% 상승 시간 t_r = ln(9) · τ ≈ 2.197 τ
- 2% 정착 시간 ≈ 3.9 τ, 1% ≈ 4.6 τ

## 직렬 RLC

- 공진 주파수 f0 = 1 / (2π √(L C))
- 품질계수 Q = (1/R) √(L/C)
- -3 dB 대역폭 BW = f0 / Q
- L = 1 mH, C = 1 µF, R = 10 Ω 이면 f0 = 5032.9 Hz, Q = 3.162, BW = 1591.5 Hz

## 저항 분압기와 전력

- Vout = Vin · R2 / (R1 + R2)
- 전류 I = Vin / (R1 + R2)
- 저항 소비 전력 P = I² R = V² / R

## CMOS 인버터

- 스위칭 문턱 Vm 은 출력이 VDD/2 를 지나는 입력 전압
- NMOS·PMOS 의 구동 세기(KP·W/L)가 같으면 Vm ≈ VDD/2. PMOS 가 약하면 Vm 이 낮아진다
