# 소자 라이브러리

자주 쓰는 소자의 SPICE 모델 카드를 모아 두었다. 교과서식 근사 모델이며 제조사 공식 모델이 아니다(데이터시트와 수치가 다를 수 있다).

## 쓰는 법
1. `search_parts(query, kind)` 로 찾는다. 예: `search_parts("제너")`, `search_parts("", kind="npn")`.
2. `get_part(name)` 으로 모델 카드와 연결 예시를 본다. 예: `D1 anode cathode D1N4148`.
3. `run_simulation` 이나 `run_sweep` 에 `parts=["1N4148"]` 처럼 이름을 주면 모델 카드가 넷리스트 끝에 자동으로 붙는다. 넷리스트에서는 **model 이름**(D1N4148, Q2N2222 …)을 쓴다.

## 주의
- `parts` 에 준 이름과 같은 `.model` 줄이 넷리스트에 있으면 라이브러리 카드가 그 줄을 대체한다(응답의 `parts_applied` 에 표시). 직접 쓴 모델을 쓰려면 `parts` 를 비운다.
- 소자 줄에는 model 이름을 쓴다(`D1 a k D1N4148`). 부품 이름(`1N4148`)을 쓰면 도구가 model 이름으로 바꿔 주고, 제너를 `Z1` 로 시작하면 `DZ1` 로 바꾼다(다이오드는 D, 트랜지스터는 Q, MOSFET 은 M, 연산증폭기는 X 로 시작해야 한다). 바뀐 내용은 응답의 `parts_applied` 에 적힌다.
- 제너는 역방향으로 넣는다: `D1 0 out DZ5V1` 처럼 캐소드(첫 노드)가 높은 전위 쪽.
- 전류원 `I1 a b 1m` 은 소자 안에서 a → b 로 흐른다(a 에서 빼내 b 로 넣음). 다이오드에 순방향 1 mA 를 흘리려면 `I1 0 anode 1m` 처럼 접지를 첫 노드로. `I1 anode 0 1m` 은 역방향이라 항복 전압(-75 V 근처)이 나온다.
- 0 V 전압원을 노드와 접지 사이에 두면(`V1 a 0 0`) 그 노드가 접지에 단락된다. 전류를 재려는 전압원은 직렬로 넣는다.
- MOSFET 모델은 Level 1 근사라 스위칭 손실·몸체 다이오드는 없다.
- 연산증폭기는 출력 제한이 없는 이상 모델이라 포화를 보려면 전원 제한을 따로 걸어야 한다.
